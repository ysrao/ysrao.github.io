Featured — the SF multicell twin, variant by variant

One project, four different artifacts. They are not interchangeable: the physics model, the band and the city scene differ, so each run link below is labelled with the variant it opens.

5G NR Multicell Twin — San Francisco

github.com/ysrao/twin5GNR-multicell-SF · 1 km² tile, Telegraph Hill / North Beach (37.801105, −122.404175)

A three-site, nine-sector 5G NR layout at 3.6 GHz over a San Francisco city scene, with a 28 GHz small-cell layer. All figures are ray-traced or modelled simulations, not measurements. Pick the variant you want — each link opens a different artifact:

Run a variant

  • Run the artifactOpen-scene version (v16) — Sionna RT on the open city scene built from DataSF building footprints; the paper version↗
  • Run the artifactSionna ray-traced version with vegetation (v7) — fused-mesh scene plus the ITU-R P.833 tree layer from 1,919 surveyed street trees↗
  • Run the artifact3GPP-only version with tower dragging (v7) — no ray tracing; TR 38.901 formula model, drag the towers and the map recomputes live↗
  • Run the artifact28 GHz small-cell version (v8) — sixteen small cells × 3 sectors on the same tile, ray-traced at 28 GHz↗
  • Run the artifactLanding page — the project’s own front page, listing all versions above↗

Code, notebook & data

  • View the codeRepository — scene, site file, scripts and all four variant pages↗
  • Run in ColabNotebook — every trace behind the open-scene page: full tile, tower-B window, sensitivity runs, tower-shift sweep (free T4 GPU)↗
  • Read the resultsResult files in the repo — per-receiver RSRP for the full tile and the tower-B window, plus the Apple M3 cross-check runs↗

Simulation bench and training code for “Semantic and Task-Oriented Encoder/Decoder Pair for IoT Sensors” (Yenamandra, Nsofu, Ram) — learned vs hand-crafted encoders across flood, dust, cyclone and metering cases, including the India flood record.

Semantic mIoT over NTN — evaluation results

github.com/ysrao/ntn-eval · github.com/ysrao/semantic-miot-ntn (paper-cited)

Trace-driven results for task-oriented semantic communication over non-terrestrial networks (SPACOMM 2027): 42.6× byte reduction, flood-warning recall 0.93 vs 0.16, supportable devices per beam and energy — negative findings kept in.

  • View the codesemantic-miot-ntn — the paper-cited repository↗
