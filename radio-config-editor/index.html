Configure the radio stack

Set carriers, channel behavior, topology, traffic, and slice constraints. Export a schema-v1 Python config and a local run script for the Sionna 2.2.0 twin.

Sionna 2.2.0 target
The simulation runs on your machine, not in this browser.
  1. Download the v4 code zip and unpack it.
  2. Install its Python requirements as described in the README.
  3. Download radio_config.py and run.sh here into the code folder.
  4. Run bash run.sh. The script sets RADIO_CONFIG=./radio_config.py before starting the twin.
