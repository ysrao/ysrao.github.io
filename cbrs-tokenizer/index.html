The transparent parametric model uses free-space path loss at the selected band center plus the entered off-axis, clutter, and terrain terms. Radar activity factors are scan-dwell shares (azimuth beamwidth ÷ 360°): ≈0.4% for a 1.4° rotating surveillance beam — the fraction of time the beam illuminates the site, i.e. the closed-window share (shipborne search sets with wider beams run higher, e.g. ≈0.9% for a 3.3° beam). This is not the radar's pulse duty (~0.1% within a dwell); the long-term time-average is dwell × pulse duty.
